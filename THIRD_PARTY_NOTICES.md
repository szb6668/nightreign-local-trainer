# Research references and third-party material

The distributed application uses Windows APIs and .NET Framework platform libraries. No third-party cheat table, game executable, game asset, save file, driver, injected DLL or third-party trainer implementation is included in this repository or its release package.

The following projects were consulted while investigating types, field layouts and instruction patterns. Their names, code and other material retain their respective rights and license terms. A reference is not a claim that their source is licensed under this project's license.

- [kwwsyk / Elden-Ring-Nightreign-Cheat-Table](https://github.com/kwwsyk/Elden-Ring-Nightreign-Cheat-Table): historical field research. The author's outdated pointer chains were not used as current addresses.
- [ColonelRVH / The Cheat Script](https://www.thecheatscript.com/2025/05/elden-ring-nightreign.html): credited reference for comparing stat and currency instruction patterns. The reference table and its scripts are not redistributed.
- [vswarte / fromsoftware-rs](https://github.com/vswarte/fromsoftware-rs): type and RTTI context. Nightreign offsets and native flag ordering were independently checked against the supported local build.
- [Loukious / NightreignTideTimer](https://github.com/Loukious/NightreignTideTimer): timer-manager identification and time-field research. The timer code is not bundled as a runtime dependency.

ELDEN RING NIGHTREIGN and related names belong to their respective owners. This project is unofficial and is not endorsed by the game's developers or publisher.
