# Publication scope

This repository contains the trainer's C# source, build/test scripts and documentation. Release archives contain the trainer executable, its launcher, these notices, and a checksum file. Private development directories are deliberately not synchronized into this repository.

Excluded from publication: game executables and DLLs, game archives and parameters, launch/anti-cheat modifications, third-party reference CT files, local process observations, save files and backups, logs, private configuration, account identifiers and credentials.

Relevant GitHub policies reviewed during preparation:

- [Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies)
- [Active Malware or Exploits](https://docs.github.com/en/site-policy/acceptable-use-policies/github-active-malware-or-exploits)
- [DMCA Takedown Policy](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy)

Those policies do not constitute project-specific approval. Intellectual-property obligations, lawful use and any applicable game terms remain separate considerations. This repository does not claim that GitHub or the game's publisher has approved it.
