# Security and rights concerns

This application opens the locally selected game process and writes supported in-memory values only when features are enabled. Its normal operation can change game outcomes and, for resource edits, persistent save data. It is intended for authorized local testing.

Please open a GitHub issue for a reproducible bug, security concern, unintended effect, or attribution/rights question. Do not attach access tokens, account identifiers, unredacted logs, game binaries, or save files. Describe the application version, game executable hash, enabled features and reproduction steps instead.

The maintainers can review or remove affected material if a substantiated security or rights concern is reported. No anti-cheat, license, DRM, or reward-validation bypass is provided by this project.
